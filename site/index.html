Questions

Asked, and answered.

What is kkcode?

A desktop app that runs Claude Code and Codex side by side. Each thread can live in its own git worktree, and the sidebar shows which one needs you.

Which agents does it run?

Claude Code through the Agent SDK, and Codex through its app-server protocol. Pick the agent and the model for each thread.

Do I need new API keys?

No. kkcode uses the claude and codex CLIs you are already signed in to.

Where does my code go?

Nowhere new. Agents run on your machine against your repositories. Keys such as a Linear token are kept in the OS keychain.

Does it replace my editor?

No. kkcode is the harness around the agent loop: start, steer, review, ship. Open the worktree in your editor whenever you want to.

Which platforms are supported?

macOS on Apple Silicon, and Linux as an AppImage.
