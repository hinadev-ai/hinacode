# Roadmap

We've added a lot of features. Now we reduce and refine them.

## Principles

- Subtract before you add.
- Start from what the developer feels. A feature serves a developer need, not the other way around.

## Features today

- Threads for Claude Code, Codex and Muse Code, with inbox, pins and archive
- A worktree per thread, including worktrees from a pull request
- Composer with model picker, thread options, queued messages, mentions and attachments
- Inline approvals, agent questions and steering a running turn
- Terminal drawer
- Side panel: Details, Files, Changes, Git, Pull requests, Agents, Browser and Tiny VM
- Pull request links, checks, merge and watch
- Built-in MCP server and Linear tools
- Remote mode with the phone app, and clouds
- Automations from webhooks, GitHub, Linear and Slack
- Command palette, search and notifications
- Usage limits, token usage and context window in the status bar
- Auto update
- English, Traditional Chinese and Japanese

## What we work on next

- Terminal refinement
- File explorer
- Remote and mobile interaction
- Pull request handling
- GitLab and GitHub Enterprise
- Relay
- Input composer
- Thread status display
- UI tidy-up
- Website tidy-up
- Localization
